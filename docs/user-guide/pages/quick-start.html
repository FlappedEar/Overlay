Quick start

Two short walkthroughs: making an overlay video, and making one from a track day of recordings.

Make a telemetry overlay video

You need an MP4 or MOV video and a VBO or RCZ telemetry file from the same session.

  1. Start FlappedEar Overlays. On the Welcome screen click Choose video and pick your video, then Choose telemetry and pick your VBO or RCZ file. Click Enter Studio →.
  2. The preview shows the video with the default Track Day overlay. To try another look, pick a template under Layout template and click Apply template.
  3. Synchronize. In the Inspector open the DATA tab.
    • GoPro with GPS: click Auto Sync GoPro GPS. A result of 75 % confidence or more is applied automatically; otherwise review it and click Apply.
    • Other cameras: enter the Telemetry offset (seconds) so that a clear event (pulling away, braking) lines up. See Manual timing.
  4. Press Space to play and check the overlay at a few points.
  5. Adjust widgets. Drag them in the preview, resize with the amber corner handle, and change details in the WIDGET tab. Add more from Add widget.
  6. Save the project with ⌘S.
  7. Export. Click Export, choose an output file, keep Recommended quality, choose Entire video, Custom timecode or Single lap · hotlap, and click Export.

Export needs FFmpeg; see Installing FFmpeg.

Export a single hot lap

  1. Add the Current lap time widget and, in the WIDGET tab, tick Show one lap only (hotlap). Keep Best lap of this recording or choose a lap.
  2. Optionally add Best lap time and Lap delta.
  3. Open Export. It starts in Single lap · hotlap mode with the same lap. Choose a Handle of 5–8 seconds and export.

Lap timing needs a start/finish gate in the telemetry; see How laps are found.

Overlay a track day

  1. Choose File › Import telemetry runs…, select the day's VBO or RCZ files and click Create event. For RaceChrono, VBO exports with calculated G give the best G data.
  2. Pick the run you filmed in the run picker in the header, then open its video and synchronize it.
  3. Open Export and choose Single lap · hotlap. The dialog finds the day's best lap: Select the day's best lap picks it in this run, or Open … switches to the run it is in.
  4. Save the event with ⌘S.
