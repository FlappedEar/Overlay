Overlay widgets

Widgets are the gauges, bars, maps and tiles drawn over the video. The preview and the exported video use the same scene, so what you arrange in the editor is what you export.

Adding and arranging widgets

  1. In the left sidebar, open Add widget and click a tile. The widget is added to the scene and selected.
  2. Drag it into place in the preview, and drag the green corner handle to resize it.
  3. Fine-tune it in the Inspector's WIDGET tab.

A scene holds at most 256 widgets. Duplicate (at the bottom of the WIDGET tab) copies the selected widget slightly offset; Delete removes it without confirmation.

A whole arrangement can be stored and reused as a layout template.

How widgets read telemetry

Most widgets have a Source channel selector. Its first entry, Automatic, uses the channel the application recognised for that purpose, such as speed, RPM, throttle, brake, heart rate or G. The other entries are the channel names of the loaded file, so you can bind any recorded channel. How channels are recognised is described in Telemetry data.

  • Values follow the playhead in time, not in frames. Preview and export look up telemetry at the exact time of each frame.
  • Displayed values are lightly smoothed so numbers do not flicker. Recorded data is never changed.
  • When there is no value at the current moment (outside the recording, inside a gap, or a channel the file does not have), widgets show an em dash —, an empty bar or no needle/dot. No other channel is substituted.
  • A short gap between samples is bridged on screen: the last value is held for up to 0.75 seconds (2 seconds for heart rate) before the widget shows no data.

There is no gear channel recognition. Gear widgets show their fallback text until you pick the gear channel yourself.

Widget catalog

The names below are the tiles in Add widget.

Speed

Label, large value and unit on a panel. Automatic source: speed. The value is converted from km/h to mph only when Unit is exactly mph (lower case); any other unit text only changes the label. The Show speed gauge option currently has no visible effect.

RPM

Label, value, unit and an optional horizontal bar scaled to Maximum. At or above Warning RPM (default 6500) the value and bar turn red. Options: Show RPM bar, Warning RPM.

Heart rate

Heart icon, label, value and unit (default bpm). Heart rate comes from the imported VBO or RCZ recording; there is no separate heart-rate source. Option: Show heart icon.

Pedals

Two rows, throttle and brake, each with a percentage and a fill bar.

SettingMeaning
Accelerator channel / Brake channelChannels for each row. Automatic uses the recognised throttle and brake channels.
Accelerator label / Brake labelRow labels (default Throttle, Brake).
Accelerator min/max, Brake min/maxThe values that mean an empty and a full bar (default 0 and 100).
Accelerator color / Brake colorBar colours.
Show values, Bar radiusShow the numbers; rounding of the bars.

If the recording has no brake channel, the brake row shows — and an empty bar. Brake data is never estimated from other channels.

G-Force, F1 G-Force Radar and G-Force Bar

All three use a lateral and a longitudinal channel. Each axis has its own channel selector and an Invert … axis option, which flips only the display, not the data. Both axes must have a value; otherwise the dot is hidden and the value shows —.

  • G-Force: a circle with crosshair and a moving dot, plus the combined G (for example 0.82 g). Settings: G range (default 2), Dot size, Decimals, Grid color, Show combined G.
  • F1 G-Force Radar: a dark circular field with concentric rings. The dot's distance from the centre is the combined G. Settings: Max G (default 1.5), Ring step (default 0.25), Show crosshair, Show center box, Radar background, Dot color, Grid color.
  • G-Force Bar: a horizontal bar filled by combined G ÷ Max G, with a label and value. The number shows the true combined G even when the bar is full. Settings: Max G, Label, Decimals, Bar radius, Show label, Show value, Fill color, Bar background.

Combined G is √(lateral² + longitudinal²). For RaceChrono data, the calculated G channels from a VBO export give the best result; see RaceChrono G channels.

Track

The GPS outline of the whole recording with a marker at the current position. It needs GPS in the telemetry. The outline is drawn once; only the marker moves during playback. The map stretches with the widget box, so keep the box roughly square for a true shape. Settings: Track line and Current-position marker colours, Line width, Marker size, Track padding, Mirror X, Mirror Y. The marker is hidden outside the telemetry range.

Custom

Shows any channel with your own label, unit and number format. It has no automatic channel: choose a Source channel first. If Label is empty, the channel name is shown.

Tyres

A top-down car with four corners (FL, FR, RL, RR) showing tyre temperature and pressure. Channels are detected from their names (see Tyre channels); there is no channel selector. Temperature is shown in °C. Pressure is shown in the chosen Pressure unit, bar or psi, converted from the recorded unit. A dash means that corner has no data at that moment.

Settings: Label, Temperature and Pressure check boxes, label text (default TYRES), Pressure unit, Cold below (°C) (blue) and Hot above (°C) (red). Leave the thresholds empty to turn colouring off.

Retro Custom

A single-row panel: icon, label, value and unit. Labels OIL, ATF and COOLANT get a matching icon automatically. Like Custom, it needs a chosen channel. Extra settings: Panel color, Value color, Label color and Text when channel is unavailable.

Arc gauge and Dial gauge

  • Arc gauge: an arc filled from Minimum to Maximum, with value, label and optional min/max numbers. Automatic source: speed. Settings: Start angle, End angle, Arc width, Inactive track colour, Show value, Min / max.
  • Dial gauge: a dial with tick marks and a needle. Automatic source: RPM. Settings: Start angle, End angle, Major ticks (2–30), Minor ticks (0–10), Needle color, Tick color, Show value, Ticks.

Angles are in degrees, measured clockwise from the 3 o'clock position.

Data strip

Four value slots in one panel (default speed, RPM, throttle, brake). Under Overlay channels: Columns (1–4; fewer columns wrap the slots into rows), Separators, Separator color, and for each CHANNEL 1–4 a channel, Label, Unit and Decimals.

Lap and speed comparison tiles

Six independent tiles, each with its own position and style. They need lap timing, which requires a start/finish gate in the telemetry and usable GPS (see Lap timing).

TileShows
Best lap timeThe best completed lap so far in the recording, and its lap number.
Current lap timeThe running time of the current lap, and its number. Shows READY before the first start-line crossing.
Lap deltaTime gained or lost against the best completed lap at the same track position.
Best-lap speedThe best lap's speed at the same track position.
Current speedCurrent speed.
Speed deltaCurrent speed minus best-lap speed at the same position.
  • Delta tiles draw a centre-zero bar. Green means better (less time, more speed), red means worse. Gauge range (seconds) (1–60, default 10) and Gauge range (km/h) (1–300, default 30) set the bar's full scale.
  • Comparison speeds are always in km/h.
  • Lap time decimals (1, 2 or 3) sets the precision of the Best and Current lap time tiles.
  • Laps with incomplete GPS keep their measured time but are not used as the best-lap reference. Delta tiles show a dash until an eligible lap has been completed.

Hotlap mode

On the Current lap time tile, Show one lap only (hotlap) makes the tile show 0:00 until the chosen lap starts, count during that lap, and then keep its final time. Choose the lap from the list (Best lap of this recording or a specific lap) or click Use the lap at the playhead. When you then open Export, it starts in Single lap · hotlap mode with the same lap.

Retro widgets

A family of period-style widgets, used by the 2000s Grand Prix template.

  • Retro RPM: a round analog tachometer with numerals in thousands, a red warning zone, needle and digital value. Settings: Dial color, Needle color, Dial background, Background opacity.
  • Retro gear: a light bar reading Gear and the value. Choose the gear channel yourself. Settings: Text when channel is unavailable, Panel color, Value color.
  • Retro pedal: a bar filled between Minimum and Maximum, with optional percentage. Settings: Show percentage, Fill color, Empty color.
  • Retro speed: a segmented speed arc (low, middle and high colours) with the rounded value. Settings: Segments (5–40), Low, Middle, High, Empty.
  • Nameplate: a two-band plate. Each field shows a channel value, or its Fallback text (for example a driver name) when there is no value.

New Retro RPM, Retro pedal and Retro speed widgets are bound to RaceChrono RCZ OBD channel names (rpm-obd, accelerator_pos-obd, velocity-obd). If your file uses other names, the widget shows no data. Select the correct channel, or Automatic, in Source channel. The selector may already display Automatic while the stored name is not in your file; select it again to apply it.

At its default size the Retro speed arc cuts off its lowest segments, as in the picture above. This is a known defect (KAN-140).

Logo

Shows the Flapped Ear Telemetry logo. Custom images are not supported. Settings: Logo opacity and Logo scale.

Value formatting

For widgets that use the Telemetry & format section, the displayed number is:

value × Multiplier + Value offset, limited to Minimum…Maximum when Clamp is on, then written as Prefix + number with Decimals + Suffix, followed by Unit when Show unit is on.

Use Multiplier and Value offset for unit conversions, for example multiplier 1.8 and offset 32 to show a °C channel in °F. The Unit field is only a label (the one exception is mph on the Speed widget). There is no global unit setting.

For bars, arcs and dials, Minimum and Maximum also define the empty and full positions.

Position, size, scale and rotation

  • X and Y are the top-left corner and W and H the size, all as fractions of the video frame (0 to 1). A layout therefore keeps its proportions at every export resolution.
  • Scale enlarges the widget box and its contents together. The widget is kept inside the frame, so the maximum scale depends on its size.
  • Rotation turns the widget around its centre. Selecting and dragging follow the rotated shape.

Font size

Auto (the value 0) lets the widget size its text from its box. A number from 1 to 200 sets the main text size in pixels on a 1920 × 1080 frame; it is scaled proportionally for other frame sizes, so preview and every export resolution look the same. The control is offered on Speed, RPM, Heart rate, Custom, Retro Custom, Arc gauge, Dial gauge, G-Force Bar, Tyres and the Retro widgets.

Colours

Each colour has a swatch that opens the system colour picker and a text field for a hex value such as #55d76a. An invalid value reverts to the default.

Cues: timed appearances

By default a widget is visible for the whole video. Cues make it appear only at chosen times, like broadcast graphics.

  1. Select the widget and open the CUES tab.
  2. Move the playhead to where the widget should appear and click Add cue at …. A 5-second cue with a fade is created.
  3. Adjust Start (s), Duration (s), Fade in (s), Fade out (s) and Entrance (Fade, Pop or Slide up). Move start to playhead moves the cue to the current time.

A widget with at least one cue is hidden outside its cues. Cues may overlap. Remove deletes one cue and Clear all cues deletes all of them. Cues are saved in projects and templates. Each widget can have up to 256 cues, and a scene up to 4,096 cues in total.
