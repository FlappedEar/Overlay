Limitations and status

FlappedEar Overlays is in development (version 0.2.0). This page lists what is known not to work yet, so you can plan around it.

Status

  • There is no public release. Test builds are not signed with a Developer ID or notarized.
  • Development and testing focus on macOS (Apple Silicon). Windows builds are paused.
  • Automated tests use synthetic data. Real-recording testing has covered a limited number of recordings and one Mac setup. Analysis features based on segments, corners, coasting, driving states and temperatures still await feedback from real track use.

Video and export

  • Only MP4 and MOV files can be opened. Export writes H.265/HEVC MP4 only, at the source frame rate or half of it, never upscaled.
  • HDR (HLG, PQ) and Log footage, video with rotation metadata, and video with non-square pixels can be edited but not exported. HDR is never silently converted to SDR.
  • GoPro chapter recordings play as one timeline but cannot be exported yet. Automatic synchronization reads GPS from the first chapter only, and relinking moves only the first chapter.
  • FFmpeg is not included and must support the required filters; FFmpeg 8.1 or newer is needed, and older versions such as 8.0.1 or 6.1.1 fail.
  • The HEVC encoder is chosen automatically and cannot be selected.
  • Completed with warning is used only when 1 to 10 frames are missing at the very end; any other validation failure fails the export.

Telemetry

  • Supported formats: VBO and RaceChrono RCZ. VBO is verified with RaceChrono Pro 10.2.4. Other VBO sources need a declared coordinate unit for GPS, and other RaceChrono versions lose their timing gates.
  • RCZ: one uninterrupted, non-resumed session per file; no calculated G.
  • Lap timing requires exactly one recorded start gate and usable GPS. Manual start/finish placement is not available.
  • There is no automatic gear channel recognition.
  • Automatic synchronization needs GoPro GPS and always uses a time scale of 1.
  • Alternative recordings are never combined automatically. Channel fusion needs a successful clock check and your approval, and has been validated with synthetic data only.

Editor

  • No undo/redo, layer locking or layer stacking order control in the overlay editor.
  • No drag-and-drop into the editor window (the Analysis window accepts dropped recordings).
  • The Logo widget shows only the application logo; custom images are not supported.
  • Some widget settings exist only in templates and have no control in the Inspector (for example the Retro Custom icon and stacking, and comparison tile labels). The Speed widget's Show speed gauge option has no visible effect.
  • Template import and export failures are not reported with a message.
  • There is no preferences window, and project files do not open by double-clicking in Finder.

Analysis

  • No background map tiles; maps show the GPS trace only.
  • Single-lap charts use time on the horizontal axis; comparison charts use track position. This cannot be switched.
  • Segments are approved per run. The Corner Analyzer needs the same approved segments on both laps.
  • Theoretical best is a sum of the fastest sectors. A validated "realistic potential" lap is not implemented.
  • Day-level results are calculated within one track configuration and one day. Reusable track and vehicle profiles and comparisons across days are not implemented.
  • The day report does not open automatically after import.
  • Session trends are drawn in recording order without showing the length of breaks.
  • VBO channel units are not read, even when the file's header declares them, so VBO values are shown without units. RCZ units are kept.
