Layout templates

A template is a complete overlay arrangement: widgets, positions, channel bindings, styles, cues and groups. Use templates to start quickly and to reuse a layout across projects.

Built-in templates

A new project starts with Track Day. The built-in templates cannot be changed or deleted, but you can apply one and save the result as your own.

Some template widgets are bound to channel names that your recording may not have. For example, the temperature tiles in Motorsport Broadcast HUD and the retro widgets in 2000s Grand Prix show — until you select your own channel in Source channel. Check every widget after applying a template.

Applying a template

  1. In the left sidebar under Layout template, choose a template from the list. Its description appears below the list. Choosing does not change the scene yet.
  2. Click Apply template.

Apply template replaces every widget in the current scene. It does not merge, and there is no undo. Save your own layout first if you want to keep it.

Saving your own templates

  • Save as new stores the complete current scene as a new custom template. Enter a Name (required) and an optional Description, then click Save template. The scene needs at least one widget.
  • Save current overwrites the custom template you applied (or just created) with the current scene, keeping its name and description. If the active template is built-in, or you have only selected a template without applying it, Save current opens Save as new instead.
  • Delete removes the selected custom template immediately, without confirmation. Built-in templates cannot be deleted.

Up to 128 custom templates can be stored. They are kept separately from projects, in the application's settings folder (see Where files are stored), and are available in every project.

Sharing templates

  • Export… writes the selected template, built-in or custom, to a .fettemplate file.
  • Import… reads a .fettemplate (or .json) file and adds it to your custom templates. Files larger than 2 MiB, or containing unknown widget types, are rejected.

If an import or export fails, no message is currently shown. If the template does not appear in the list after Import…, the file was not accepted.

If custom templates cannot be loaded

If the template store is damaged or too large, a red message appears under Layout template (for example Custom templates could not be loaded from …). The file is left untouched and saving templates is disabled, so nothing is overwritten. Built-in templates remain usable. Quit the application, move the damaged layout-templates.json aside, and start again; see Troubleshooting.
