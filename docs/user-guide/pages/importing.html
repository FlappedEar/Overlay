Importing video and telemetry

An overlay project needs one video and one telemetry recording. A track-day event can hold many recordings, each as its own run.

Video

Use Open video in the header, File › Open Video… (⇧⌘V) or Choose video. The file picker accepts .mp4 and .mov files.

  • One ordinary file opens directly.
  • Selecting several files, or a single file with a GoPro chapter name, opens the Video chapters review first.

The application reads the video's properties (size, frame rate, codec, bit depth, colour, audio) with ffprobe, so FFmpeg must be installed even before you export; see Installing FFmpeg. Video without GoPro metadata imports normally; only automatic synchronization needs it.

Videos with a variable frame rate, HDR or Log colour, rotation metadata or non-square pixels can be opened, played and edited. Some of them cannot be exported yet; see Sources that cannot be exported.

GoPro chapters

GoPro cameras split long recordings into chapter files. The application recognises GoPro chapter names (for example GX010123.MP4, GX020123.MP4 on HERO6 and later, and GOPR0123.MP4, GP010123.MP4 on older models) and offers them as one recording.

  1. Open all chapter files of a recording together (1 to 64 files).
  2. The Video chapters dialog lists each recording group with its chapters, durations, size, codec, frame rate and creation time.
  3. Check the warnings, reorder chapters with ↑ and ↓ if needed, and click Use this recording.

The dialog warns about:

  • a missing chapter (the video would jump over it);
  • a chapter chosen more than once (the copies are left out);
  • an unreadable chapter (the group cannot be used);
  • chapters that differ in codec, size or frame rate;
  • chapters whose creation times overlap or leave a gap of more than a few seconds;
  • files without usable creation times (the order then comes from the names only).

The chapters play as one continuous timeline. A missing or changed chapter plays as a gap, and telemetry time continues across it.

Exporting a video made of several chapters is not available yet. Automatic synchronization uses only the first chapter's GPS. To export, open a single video file.

Telemetry

Use Open telemetry in the header, File › Open telemetry… (⇧⌘T) or Choose telemetry. Two formats are supported:

FormatTypical sourceNotes
.vboRaceChrono Pro VBO exportIncludes RaceChrono's calculated lateral and longitudinal G when they are enabled in the export. Verified with RaceChrono Pro 10.2.4.
.rczRaceChrono session archiveKeeps each sensor's original recording rate. One uninterrupted session per file. Contains no calculated G.

On success the status bar shows Telemetry opened: N samples, M numeric channels., followed by up to three parser warnings. Details of supported content, recognised channels and limits are in Telemetry data.

In an event, Open telemetry… replaces the active run's primary recording; it does not add a run.

Importing a track day

A day at the track usually produces several recordings. Import them together into an event, where each recording becomes a run. File › Import telemetry runs… lets you check each file before anything changes.

  1. Select 1 to 64 VBO/RCZ files.
  2. In the Import runs dialog choose Create a new event (enter an event name) or Add runs to current event.
  3. For each file choose Import as a run, Skip this file or Same run as: …. Each row shows the duration and number of complete laps, and a status: ready, duplicate or error. Tick Show file details and import warnings for paths, parser warnings and possible matches.
  4. Click Create event or Add reviewed runs.

Files are checked again just before they are committed. If you have unsaved changes, save them before creating a new event.

Choosing the run to edit

When an event has more than one run, the header shows a run picker next to the file names. Choose a run to show its telemetry, video and synchronization in the editor; the overlay layout is shared by all runs. The picker is unavailable while a project loads, an export runs, or a question about unsaved changes is open. The Export dialog finds the day's best lap across all runs by itself (see Export).

VBO and RCZ of the same session

If you exported the same session both as VBO and as RCZ, they belong to one run:

  • In the review dialog, choose Same run as: …. The run uses the file you link to; the other file is kept with that run.
  • Unknown clocks, different dates and ambiguous matches stay as separate runs.

Channels of the two files are never combined automatically.

Duplicates and naming

  • Two files with identical content are reported as duplicates and imported once.
  • Runs are named Session 1, Session 2, … in recording-time order. Recordings without a clock follow in import order.
  • The recording date and time come from the file's content. File names and file dates are never used.
