The editor window

The editor is where you load a video and a telemetry file, arrange overlay widgets on the picture, set timing and export the result.

Welcome screen

When no project, video or event is open, the application shows the Welcome screen, headed Your track day, in detail. It offers two paths:

  • Lap Analysis → closes the Welcome screen and opens the Analysis window. Video is not needed for analysis.
  • The three cards build an overlay project:
    1. 1 · Video clip: Choose video picks an MP4 or MOV file.
    2. 2 · Telemetry: Choose telemetry picks a VBO or RCZ file. This step is optional at this point.
    3. Saved project: Open project… resumes a saved .fetproject.

Enter Studio → becomes available once a video is chosen and opens the editor. You can return to this screen with File › Welcome.

Working in the preview

With no video loaded, the preview shows Open an MP4 or MOV to start building the overlay and a Choose video button. Drag-and-drop of files is not supported; use the button or the File menu.

Once a video is ready, the overlay widgets are drawn on top of it and can be edited directly:

  • Click a widget to select it. Shift-click adds it to, or removes it from, the selection.
  • Drag a widget to move it. It stays inside the picture. Dragging a grouped widget moves the whole group.
  • Drag the green handle at the bottom-right corner of the selected widget to resize it.
  • Click empty space to clear the selection.
  • Double-click a widget or the picture to toggle full screen.

If the video cannot be decoded, the preview shows Video playback failed with the reason.

Playback and the timeline

Timecodes are shown as SMPTE HH:MM:SS:FF (hours, minutes, seconds, frames; non-drop-frame). The end timecode is the last real frame of the video, and playback stops on that frame.

Use the play/pause button or Space, drag the slider, or use the arrow keys to seek (see Keyboard shortcuts). If the selected widget has cues, green marks above the slider show where they are.

Layers and groups

The Layers · N section lists every widget in the scene. Each row shows a marker (● selected, ◆ grouped, ○ other), the layer name and an eye button that hides or shows the widget. Hidden layers are dimmed and are not exported.

  • Click a row to select that layer (and the rest of its group). Shift-click to add or remove it from a multi-selection.
  • Group (⌘G) joins two or more selected layers so they move together.
  • Ungroup (⇧⌘G) separates the group of the selected layer.
  • Delete or Backspace removes the selected layers. There is no confirmation.

The editor has no undo/redo, no layer locking and no control for stacking order. Save the project before making large changes you might want to reverse.

The Inspector

The right sidebar has three tabs:

  • WIDGET: every setting of the selected widget. See Widget settings.
  • DATA: timing between video and telemetry, and the live value of every telemetry channel at the playhead. See Synchronizing video and telemetry.
  • CUES: timed appearances of the selected widget. See Cues.

Full-screen preview

Enter full screen from View › Enter Full Screen, the ⛶ button, the system full-screen shortcut or by double-clicking the preview. The video fills the screen and a floating bar provides play/pause, timecode and a scrub slider. During playback the bar hides after about 2.6 seconds and returns when you move the mouse or press a key. Esc leaves full screen.

Status bar messages

Most actions report their result in the status bar, for example Telemetry opened: N samples, M numeric channels. or Project saved: name. If automatic recovery data cannot be written, the status bar shows an amber warning with a SAVE button; see Recovery.
