Keyboard shortcuts

Shortcuts are shown with macOS keys: ⌘ Command, ⇧ Shift, ⌃ Control.

Project and files

KeysAction
⌘NNew Project
⌘OOpen Project…
⌘SSave Project
⇧⌘SSave Project As…
⇧⌘VOpen Video…
⇧⌘TOpen telemetry…
⌘E or ⌃EExport… (when video and telemetry are loaded)
ReturnStart the export, while the Export dialog is open and ready
⌘QQuit

View

KeysAction
⌃⌘FEnter or exit full-screen preview (the macOS full-screen shortcut)
EscLeave full screen; close a dialog
F1Keyboard shortcut reminder

Full screen uses the system shortcut, ⌃⌘F on macOS; double-clicking the preview also works. F1 shows a reminder of these shortcuts.

Playback (editor)

KeysAction
SpacePlay / pause
← / →Back / forward 5 seconds
⇧← / ⇧→Back / forward 30 seconds
Home / EndFirst / last video frame

Playback keys are disabled while you type in a field or operate a control, so typing a value never starts playback.

Editing

KeysAction
Delete or BackspaceDelete selected layers (not while typing in a field)
⌘GGroup the selected layers
⇧⌘GUngroup
Shift-clickAdd a widget or layer to the selection, or remove it

Export log

KeysAction
⌘A, ⌘CSelect all / copy in the export diagnostics
Page Up, ↑, HomeStop following the Very verbose log to read earlier lines
